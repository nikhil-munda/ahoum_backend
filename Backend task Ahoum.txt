Backend: Events Platform (Django) 
Goal 
Build a small "events" backend with auth, RBAC, search, and enrollments. The app serves 2 roles: 
Seeker and Facilitator. You must use Django's default User model (do not swap it). Signup must 
not accept username. 
Core Requirements 
1) Auth & Users 
• Stack: Django (4+), Django REST Framework; JWT via djangorestframework-simplejwt (or 
your own equivalent). 
• Default User model only. 
Signup: input is email, password, role (Seeker | Facilitator). No username field in request. 
• Email OTP verification flow: 
O POST /auth/signup → create unverified user, send a 6-digit OTP to email, store with 
TTL. 
o POST /auth/verify-email with {email, otp} → mark verified; allow login. 
o Include expiry (e.g., 5 min) and attempt limits. 
• Login 
POST /auth/login with {email, password} → returns access and refresh JWTs. 
о POST /auth/refresh to rotate/refresh tokens. 
o Unverified users cannot log in. 
2) RBAC 
• Roles: Seeker, Facilitator. 
• Enforce via DRF permissions / Django permissions. 
• All endpoints must check role & ownership where relevant. 
3) Domain Models 
• Event 
o Fields: title, description, language, location, starts_at (UTC), ends_at (UTC), capacity (int, 
optional), created_by (FK
